**Airline Delay Analysis Dashboard**
Project Overview

This project analyzes airline operational performance using Power BI to identify delay patterns, cancellation trends, and airline efficiency. The dashboard enables stakeholders to monitor key performance indicators and uncover factors affecting flight punctuality.

**Objectives**
1. Analyze airline operational performance.
2. Monitor delay and cancellation trends.
3. Compare airline on-time performance.
4. Identify peak delay periods.
5. Discover the most affected routes.
6. Support data-driven operational decisions.
